# 008 · POSSESSION — the current UI, possessed

**Thesis.** Start from what Mosh *actually looks like today* ([current-ui/AUDIT.md](../current-ui/AUDIT.md))
and change only matter and posture, never bones. The shipping skeleton — topbar,
ruler, lanes, clips, chain panel, generative drawer — survives intact because it maps
1:1 onto verified MoshOps commands. What changes: purple dashboard chrome becomes
**ink slabs with lume seams**; the toolbar dissolves into the whisper line; the rack
speaks **parameter poetry**; every agent action surfaces as a poppable deed; Moshi
takes up residence; and the two non-negotiables get upgraded *in place* (REC = ember +
room heat; position = lume playhead with a pressure pulse the clips physically feel,
plus the mono `BAR x.y` for the skeptic).

**Why this direction exists.** 003–006 explore how far the lore can go; 008 proves the
lore can land on the real product **as a skin** — zero C++ changes, the same Stage-2
swappability seam. It's the migration path: every field-notes motif demonstrated on
the layout we already ship.

**Field-notes lineage:** slabs/seams + eaten-open panels (hours, kaolti) · spectral
whisper on the playhead (marioecg) · parameter poetry (lukasspitter, BlousonRouge) ·
takes as capsules (techartist_, Jaenam97) · lime dust waveforms (obtainer, p1xelfool).

**Risks.** Restraint discipline: the seams must stay quiet or it's just neon borders;
the eaten-open animation must be rare (summon/dismiss only). Density at 64 tracks
unproven (same caveat as GULLET — blooms-on-demand is the assumed answer).

**Steal even if killed.** The slab+seam panel system and the in-place upgrade recipe
for the two non-negotiables — both apply to ANY winning direction, and to the current
production UI tomorrow.
