# Taste loop — week-1 foothold results (2026-07-19)

*Executes the week-1 scope of [`WORKSHOP_2026-07-19-taste-loop.md`](WORKSHOP_2026-07-19-taste-loop.md).
The charter's exit criterion was "the AUC table exists; one judge is promoted or ALL are
demoted (both outcomes are wins)". The actual outcome is the third one nobody priced in —
and it is load-bearing: **the label archive the whole design assumed does not exist.**
Everything below is reproducible: `python3 service/taste/build_table.py --session
~/Library/Mosh/session --families audiobox,fake,clap,mert,tunejury`.*

## Headline: the label census, not the AUC, was the informative artifact

The charter (and the 8-model panel) took as given "an accept/reject taste-label archive
with full render fingerprints, accumulating since Stage 5 … already in that [~150] range
and growing". The census (`service/taste/census.py`, golden-tested) says otherwise:

| census over `~/Library/Mosh/session` | count |
|---|---|
| accept/reject label events in the surviving log | 59 |
| — scripted-harness replays (same boot signature ×29, no listening) | 58 |
| — contradicted (accept AND reject stamped on the SAME render, no re-render between) | 58 |
| **organic accepts** (a human listened, then labeled) | **1** |
| **organic rejects** | **0** |
| renders still on disk with audio | 30 (29 FakeAdapter + 1 real SA3) |
| renders with Audiobox axes in the manifest | 1 |

Three compounding causes, all verified in the archive itself:

1. **The harness labeled into the real archive.** The verify/demo scripts run against the
   real `~/Library/Mosh` (the documented "JUCE ignores $HOME" class). 29 near-identical
   7-command boots each render ONE deterministic FakeAdapter clip and then stamp
   `accept_render` *and* `reject_render` on it seconds apart — both labels on the same
   audio, carrying zero preference information by construction.
2. **The product removed the label surface.** The 2026-06-30 re-imagine overhaul (PR #185)
   auto-applies wave renders in place — accept/reject stopped being the main loop, so
   organic labels stopped accumulating the day the flow shipped. The owner's taste signal
   since then is *reset / re-render / keep*, none of which is logged as a taste verdict.
3. **The wiped-window data loss.** SLF-CONC-001: from 07-07 to 07-18 the GUI wrote into
   the exact dir `--selftest` wipes. Whatever in-place-era organic signal existed for
   those 11 days is gone.

The one organic label: a real listening session on 06-29 (67 commands, transport
scrubbing, one `accept_render` of a real SA3 render whose manifest carries all four
Audiobox axes). It proves every pipeline stage and can train nothing.

No judge is promoted; none is demoted either — **the table cannot discriminate until the
archive has both classes.** Per the charter's stop rule, the best-of-4 reranker and the
disagreement queue were **not built** (a reranker behind an unvalidatable judge is
exactly the "embedding tourism" the charter warns about).

What DID get proven, so the table fills itself the day labels exist:

- **The probe machinery is real and golden-tested** (`service/taste/probe.py` — pure-stdlib
  deterministic logistic probe, tie-aware AUC, temporal split; `taste_probe_test.py`
  pins separable→1.0, constant→0.5, degenerate→honest refusal, 3× bit-identical).
- **The real embedding lanes run end-to-end on archived renders**: CLAP
  (`laion/larger_clap_music`, Apache-2.0, 512-d) and MERT (`m-a-p/MERT-v0-public`, the
  commercially-clean variant) both embedded the surviving WAVs under the judges venv
  (no new multi-GB venv; `service/taste/taste_cli.py` subprocess seam). Weights are
  cached locally (`setup-taste.sh --fetch-weights`).
- **Audiobox is no longer 3/4 unread**: `qa.py` has been writing the full `axes`
  (CE/CU/PC/PQ) into every render manifest since AL-006; `features.audiobox_rows`
  reads all four. The 29 FakeAdapter manifests predate that and carry only fake `pq`.
- **TuneJury runs for real** — the charter's Day-3 warm start, executed on an archive
  of one. The HF head is real (`TuneJury/tunejury` — primary head CC-BY-NC-4.0,
  `A1_clap_audio_only.pt` Apache-2.0); its README's `pip install git+…` is broken
  upstream (no pyproject in the repo), so `setup-taste.sh --tunejury` carries the
  working recipe (ISOLATED venv under `~/Library/Mosh/venvs/tunejury` — never the
  judges venv — + repo `.pth` + `torchaudio<2.8` pin, the documented torchcodec
  gotcha, + torchvision for laion_clap's import). The full frozen-CLAP+MERT→head
  pipeline scored the organic render end-to-end (`MOSH_TUNEJURY_PY` override).

   Bound in every DAW preset (Mod+Shift+F, collision-checked), rebindable via the
   settings schema, dialog in both shells, native relay is `Thread::launch`ed (no
   message-thread service-spawn freeze). vitest 9 + e2e 2 (isolated config).
