# Mosh DAW Reality Pack

Files in this pack:

- `mosh_daw_reality_model.md` — synthesized knowledge base covering cross-DAW ontology, invariants, MVP filter, user research plan, Moshi command model, and QA guardrails.
- `mosh_moshi_command_schema.json` — machine-readable starter command schema for Moshi.
- `mosh_daw_eval_suite.csv` — 200 DAW behavior regression test seeds.
- `mosh_moshi_eval_prompts.csv` — 150 natural-language Moshi eval prompts.

These files are grounded in the available Ableton Live, FL Studio, Pro Tools, Mosh scope, and browser-audio research notes.
