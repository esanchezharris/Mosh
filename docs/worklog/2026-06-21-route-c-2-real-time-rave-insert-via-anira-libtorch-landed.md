**Route C.2 — REAL-TIME RAVE insert via anira+LibTorch landed (2026-06-21).** A Tier-A `te::Plugin` (`src/plugins/transform/RaveInsertPlugin`) runs a RAVE `.ts` live via **anira 2.1.0 + LibTorch 2.4.1** (auto-downloaded by anira at configure). **All gated behind `MOSH_ENABLE_ANIRA` (OFF by default → default build byte-unaffected, 888/888).** Torch is **isolated in `RaveEngine.cpp`** (a torch-free `RaveEngine.h` interface) so the LibTorch↔JUCE header clash never touches the audio TUs. anira owns the bg inference thread + RT-safe ring buffers; the plugin reports anira's exact latency for PDC and delay-aligns the dry path for a phase-correct dry/wet. Commands `add_rave_insert`/`set_rave_param`/`load_rave_model`/`reset_rave` + snapshot `rave` field + `session.raveAvailable` (gates the UI "+ RAVE" button) — all `#if MOSH_HAVE_ANIRA`. UI: RAVE rack card (`RaveBody`) + gated button + mock. **Build it:** `cmake -S . -B build-anira -G Ninja -DMOSH_ENABLE_ANIRA=ON ...` (LibTorch ~hundreds of MB, long; reuse `-DCPM_SOURCE_CACHE`+`-DFETCHCONTENT_SOURCE_DIR_TRACKTION_ENGINE`). **Proven:** anira build links libanira+libtorch + selftest 888; **real-time render through the insert offline = dry vs wet diff-RMS 0.547, non-silent** (synthetic scripted RAVE model; `add_rave_insert modelLoaded:true`). Default green: selftest 888×3, Catch2 162, vitest 421, e2e 40, tsc. User drops real RAVE `.ts` into `~/AI/rave-models`.
