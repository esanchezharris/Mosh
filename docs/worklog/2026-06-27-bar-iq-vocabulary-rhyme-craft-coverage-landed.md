Slang/coined/NSFW words get REAL phonemes → real rhyme grading (not the spelling fallback) → the validator can verify slang rhymes. g2p lazy-loaded + memoized + ARPAbet-filtered; degrades to heuristic if absent. `setup-phonology.sh` installs g2p-en + `setuptools<81` + the nltk POS-tagger data (runtime-required). **VERIFY done: g2p-en is arm64-light (numpy/nltk, NO TensorFlow) + clean ARPAbet** (drip→D R IH1 P, guap→G W AA1 P).
  - **B — vocabulary palette** (`service/lyrics/vocab.py`, JSONL by `MOSH_LYRIC_CORPUS_DIR`): tagged word bank {word, phones, register, rhymeFamily}. Passive-leaning sources: bundled open SEED + AUTO-HARVEST from the §7 corpus (rides the existing accept→`/style_corpus` push — ZERO new C++) + manual `/vocab add`. `/get_rhymes` MERGES palette rhymes (slang SURFACES, tagged source=palette, deduped, palette-first). Phones computed once at write time via the venv (`phonology_cli.py pronounce` subcommand) so query-time needs no model.
  - **C — rhyme craft** (`core.py`): `vowels_of` / `multisyllabic_depth` (longest common trailing-vowel run; 2+ = multi) / `internal_rhyme_pairs`. The gen ranker `_evaluate` rewards depth (+0.5/syllable>1 → prefers skilled rhymes); `analyze_lyrics` reports `rhymeDepth` + `internalRhymes` (snapshot-ready for a future flow-viz; UI not yet wired).
  - **D — register** (`core.py` + `server.py`): RAW is the default — the LLM prompt explicitly permits slang/explicit ("don't self-censor"); `explicit:"clean"` is the opt-in. Clean mode filters profanity wherever it appears (palette is the profanity REGISTRY via `register_words`, so dict profanity is dropped too) while keeping slang.
