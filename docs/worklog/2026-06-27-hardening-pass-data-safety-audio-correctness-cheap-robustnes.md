# Hardening pass — data safety + audio correctness + cheap robustness (2026-06-27)

_Working note, 2026-06-27. Moved verbatim out of CLAUDE.md; content unchanged._

**Hardening pass — data safety + audio correctness + cheap robustness (2026-06-27).** From an external architecture review (notes in the session). Audited each concern against the code first — several premises were stale (autosave/save-on-quit already shipped) or already-safe (servers all bind 127.0.0.1/HTTPS; brain key bundled on purpose). Landed, each verified:
  - **A1 — project FORMAT versioning + migration + newer-file refusal.** `moshFormatVersion` stamped on the `MOSH_PROJECT` node every save (`state/Migrations.h`, header-only registry + `migrateOrRefuse`); load-time gate at all 3 `MoshEngine` load sites (temp-load→gate→swap; cold-start refusal latches `loadError` → save() no-op so a newer file is never clobbered; mid-session open/reload refusal returns an error and keeps the current project). Snapshot `schemaVersion` → named `kSnapshotSchemaVersion` + soft UI "update the app" banner. UI `versionBannerError` + `RecoveryNotice`. Tests: `tests/test_migrations.cpp` (5), `--selftest` PRJ-FMT (10), vitest.
  - **B2 — RT-safety tripwire (debug-only).** `src/audio/RealtimeAudioGuard.{h,cpp}` — `thread_local` depth + global `operator new` override under `MOSH_RT_GUARD` (Debug only ⇒ Release byte-unaffected). `MOSH_RT_SCOPE()` wraps `MasterSpectralTapPlugin`/`RaveInsertPlugin::applyToBuffer`. `tests/test_rt_guard.cpp` (4). The always-on tap runs every selftest render through the guard → 1045/1045 proves the RT path is alloc-clean.
  - **B1 — golden-audio regression GATE.** `verify.py --gate`/`--update-golden` + committed `scripts/verify-hardware/golden/manifest.json`: **PCM**-checksum (NOT whole-file — JUCE's WAV header has a non-deterministic ~784-byte bext/timestamp chunk) for the 4 deterministic renders + a diagnostic feature vector (peak/rms/centroid). Wired into `scripts/auto-loop/gate.sh:177`. Stable ×2, reds-with-feature-diff on a perturbation.
  - **A2 — cheap crash recovery.** `saveIfDirty()` before the in-process-crash-prone ops (`load_plugin`/`load_builtin`/`remove_plugin`/`accept_render`/`bounce_layer_to_clip`/`freeze_layer`) ⇒ those crashes near-lossless; `session.running` sentinel (Main.cpp mark-after-load / clear-last-on-clean-quit; ctor latches `uncleanAtStartup`) → snapshot `recoveryAvailable` → dismissable `RecoveryNotice`. `--selftest` A2 (4).
  - **C — cheap hardening.** C1: agent destructive-batch scope-limit (`screenDestructive`, blocks >10 deletes/batch, `ui/src/agent/executor.ts` + tests). C2: reap an orphaned/wedged MLX service via a PID handshake (`service.pid` = `<pid> <port>`, reaped only if it squats our port) — **proven**: a SIGSTOP-wedged orphan on 8770 was reaped by the next launch (this is the long-standing "port-8770 orphan flakiness"). C3: 8770 port-collision fallback (`server.py` tries the next ports, writes `service.port`; the host adopts it) — **proven** 8782→8783.
  - **D1 — snapshot() scaling MEASURED (measure-first).** `__bench_snapshot` run-script hook + `scripts/bench/snapshot_bench.py`: at **100 tracks × 200 notes (~20k notes) snapshot() = 330 ms / 3.7 MiB per edit** ⇒ scoped invalidation IS warranted at scale (a justified follow-up). Transport is already split off the snapshot, so a moving playhead isn't in this cost.
  - **Verified:** `--selftest` **1045/1045 ×3** deterministic (Debug, RT guard active), Catch2 **221** (+ rtguard/migrations), vitest **592** (+ versionBanner/executor-guard/RecoveryNotice), `tsc` clean, `verify.py --gate` 12/12 stable. **DEFERRED (own focused pass):** A3 full JSONL-replay recovery (wrinkles found: `seq` is per-session not monotonic; `logLine` doesn't carry result ids — a broad signature change; project-switching "which edit to replay onto"; value-based id-rebinding) — A2 + autosave already bound loss well, so this is a refinement not a gap; **scoped snapshot invalidation** (now data-justified by D1); **D2** plugin-scan AU-hang timeout + progress UI.
