**Re-imagine workflow overhaul — Phases 1–3 (PR #185, branch `claude/reimagine-inplace-wholeclip`, 2026-06-30).** Replaces the manual *render → audition on a "Neural Renders" lane → accept/reject* loop with "re-imagine just becomes the clip, one click back." **P1 (`9f06dfb4`):** wave clips auto-apply IN PLACE (`applyRenderInPlace` repoints the clip's own source; `reset_render_layer` restores `originalSourceRef`, stored ABSOLUTE + consolidated on Save-As so Reset survives a move); fixes the SA3 **8s-cap** with service-side whole-clip **tile/stitch** (`coverage: auto|loop|stitch`, in the fingerprint; `service/stitch.py`+`coverage.py`). **P2 (`5b49aa70`):** drum/MIDI auto-applies as a HIDDEN render that plays BENEATH the muted MIDI (✨ badge, `reimagineActive`). **CRITICAL ENGINEERING FACT:** the hidden audio CANNOT live on the source track — a track's instrument **synth overwrites the buffer and silences any audio clip on that track** (proven: synth-on export = 0.0 RMS; synth-bypassed = 0.276). So it lands on a dedicated, instrument-free track that **`snapshot()` EXCLUDES** (filter on `ids::moshHidden`); the producer hears it (export uses the real edit) but never sees it. `findOrCreateHiddenRenderTrack` (one shared track); `applyRenderBeneathMidi` mutes the MIDI + lands/hot-swaps the hidden clip; `kSourceMutedByLayer` discriminates beneath-vs-legacy-lane; `cmdRenderLayer` un-mutes around the bounce so a hidden-muted MIDI still re-bounces its synth. **P3 (`14d3734e`):** `reactiveTouch`/`reactiveTouchTrack` debounce-fire a background re-render when a render is live (`appliedInPlace`/`kSourceMutedByLayer`), wired into note/quantize/trim/drum edits + `set_render_param` + track plugin cmds; epoch-guard (`reactiveEpoch` captured at submit, checked in `finalizeRender`) drops superseded results; **gated OFF in headless** (`!eng.hasAudio() && !MOSH_REACTIVE_DEBOUNCE_MS` → no service spawn) so `--selftest` stays hermetic. **GOTCHAs:** (1) synth non-determinism (~0.44 RMS between identical 4OSC exports) makes sample-exact export diffs USELESS — verify.py anchors on non-silence + `__snapshot` STATE + durable-file count, not A/B/C sample diffs; (2) `createAudioTrack` is instrument-free (the default-instrument policy is only in specific command handlers), so the hidden track keeps the wave audible. **Verified:** `--selftest` **1158×3**, Catch2 **331**, `verify.py --gate` **14/14** (+`check_midi_reimagine_beneath`, +`check_reactive_rerender`), tsc, vitest **671**, e2e **117**; real SA3 P1 (in-place+Reset 0.0000, 20s whole-clip). Owner-gated: real-SA3 drum/MIDI by-ear. **PR #185** (base main; supersedes the Phase-1-only #185 description). **Merge-time addendum (2026-07-04, landing on post-FMS-Stage-2 main):** auto-apply is GATED to non-sing modes in `finalizeRender` — `mode:"sing"` keeps the legacy auditionable landing (the guide vocal must never replace the recorded take in place, and must not arm the reactive loop, which would fire multi-minute SSH renders on casual edits); sing layers never set `appliedInPlace`/`kSourceMutedByLayer`, so `reactiveTouch` stays inert for them by construction.
