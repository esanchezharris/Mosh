# "RAVE rack silent under pinned LibTorch" was one bad model, not a runtime mismatch (2026-07-16)

_Working note, 2026-07-16. Moved verbatim out of CLAUDE.md; content unchanged._

**"RAVE rack silent under pinned LibTorch" was one bad model, not a runtime mismatch (2026-07-16).** The FIT-013 verdict ("`~/AI/rave-models/*.ts` load but render silence through the insert on Windows; suspected trace-newer-than-LibTorch-2.4.1") was a false alarm with a three-part anatomy: (1) `birds.ts` **self-silences under EVERY torch runtime** — its encoder state runs away on out-of-domain input (latent rms ≈160, |z| ≈320 vs the ~N(0,1) healthy range) and the decoder underflows to exact zeros from block 2 (bit-identical in Python torch 2.4.1 vs 2.13.0; 16/17 Mac rack models healthy under 2.4.1); (2) `rave_insert_check.py`'s real-model fallback blind-picked the **first sorted .ts = birds.ts**, and the PC rack contained ONLY birds.ts; (3) the "runs fine under python" sanity check was a single 2048 block — exactly the one block birds still plays (and `kRaveWarmUp=5` burns those blocks before real audio). **Fix:** the harness's real-model mode iterates rack candidates, skip+reports `model_silent`/`load_failed` ones, fails only on pipeline signals (gaps/NaN/silent-after-reset/all-dead); `RAVE_INSERT_MODEL` (path or bare rack name) pins one model, no iteration. Unit test `rave_insert_check_test.py` (injected fake run_script, 3×-det). **Verified both platforms:** Mac fresh `deploy-anira` — synthetic lane green, real-model lane skips birds + passes ensembles, pinned-birds reproduces the PC symptom on macOS; PC (over SSH, existing FIT-013 build) **14/14** — `pluma.ts` (now copied to the PC rack) transformed/gap-free/reset-safe, birds auto-skipped. LibTorch pin NOT bumped (evidence says it's innocent); if a genuinely-too-new trace ever appears, anira v2.2.1 pins LibTorch **2.12.0** via `AniraBackends.cmake` (+ per-engine override knobs). Full diagnosis: [docs/2026-07-16-rave-rack-silence-diagnosis.md](docs/2026-07-16-rave-rack-silence-diagnosis.md); WINDOWS_PARITY.md FIT-013 row corrected. GOTCHA: a RAVE model can legitimately map non-domain input to (exact) silence — never validate a streaming model with one block, and never let a verify harness bind to one blind-picked model.
