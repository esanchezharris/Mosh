# SLF-CONC-001 — `--selftest` made hermetic against a CONCURRENT selftest, and a GUI data-loss regression found on the way (2026-07-18)

_Working note, 2026-07-18. Moved verbatim out of CLAUDE.md; content unchanged._

**SLF-CONC-001 — `--selftest` made hermetic against a CONCURRENT selftest, and a GUI data-loss regression found on the way (2026-07-18).** Every headless mode used a FIXED session leaf (`~/Library/Mosh/session-selftest`, `-undo`, `session-run-script`, ...) and `MoshEngine` wipes that dir with `deleteRecursively()` at startup, so **two concurrent runs on one host deleted each other's exports / saved edit / `mosh-log.jsonl` mid-test**. Reproduced on the pre-fix binary: two plain concurrent runs → **6 and 2 failures** across `export_audio wav/aiff`, G1 tail, G7 stems, `DRM-001` drum export, `save ok`, and the AGT-001 command-log inspector; the **totals differed too** (failures short-circuit nested sub-blocks) so a raced run wasn't even comparable to a baseline. The control — same binary, same concurrency, only distinct `MOSH_SELFTEST_SESSION` — was **1281/1281 twice, 0 failed**, which pins the session dir as the cause. (Worse still: repeating the concurrent pair on a pre-fix binary later **segfaulted both** processes once and **hung >10 min** another time, with no symlink involved — the shared dir doesn't just mis-report, it can kill the run.) **The originally-reported diagnosis was wrong about mechanism:** `selftestTempPath()` and the raw `File::tempDirectory` sites are a real but SECONDARY collision class (fixed here too — `loras-empty`, `mp-syncswitch`, `commitfail-src`, and the 4 `corrupt-*` paths were fixed names, or names hashed from CONSTANT payloads, so both processes computed the identical path); none of them touch the sections that were actually failing, which all write under `eng.sessionDir()`. **Fix:** `src/engine/SessionPaths.h` owns leaf policy in one place — an explicit `MOSH_SELFTEST_SESSION` still wins **verbatim** (gate.sh / verify.py / installed-app-gate.sh read artifacts back out of that exact path, unchanged), otherwise a headless run auto-isolates to `<base>-auto-<pid>-<uuid8>`. The legacy fixed path survives as a **symlink to the most recent run** (so `scripts/validate-command-log-contract.sh`'s default path and muscle-memory inspection still work — verified), stale auto dirs are pruned only after **24 h untouched** (a live concurrent run must never look like garbage), and the run **prints its session dir** at startup. **BONUS — a separate, severe regression found and fixed:** `Main.cpp`'s ternary fell through to `"session-selftest"` for **every** launch including the plain GUI, and **#246 (2026-07-07) inverted `MoshEngine`'s precedence** so that name beat the GUI `"session"` leaf — i.e. since 07-07 **the interactive app has been living in the exact dir `--selftest` wipes**. Proven on disk both ways: pre-fix, a plain GUI launch bumped `session-selftest` and left `session` cold; post-fix it writes `session/mosh-log.jsonl` and touches no harness dir. `harnessSessionBase()` keeps the GUI out of harness dirs (a bare `MOSH_NO_AUDIO=1` launch deliberately still gets a harness base — it wipes), plus a fail-closed `MoshEngine` guard that refuses to `deleteRecursively()` the `"session"` leaf. Regression guards: `scripts/selftest-concurrency-check.sh` (runs 2 plain concurrent selftests; asserts equal totals, 0 failed, distinct dirs — RED-proven, it fails against the pre-fix binary) + an always-on selftest check that this run's session dir is private, not a shared fixed path. Verified: **concurrent plain 1681/1681 ×2, 0 failed, isolated dirs**; serial ×3 **1682/1682 deterministic**; Catch2 **825 assertions / 168 cases** (incl. 8 new `[sessionpaths]` units); explicit-leaf contract **1681/1681**, dir verbatim. **Pre-existing, NOT fixed (out of scope):** `validate-command-log-contract.sh` reports `missing expected commands: add_render_layer, reject_render` — reproduced identically against a pre-fix binary's dir and a non-symlink path, so it's a stale expectation vs the current selftest command mix, not path breakage. **GOTCHA:** `commandLine.contains("--selftest")` is also true for `--selftest-undo`, so `harnessSessionBase()` must match undo FIRST.
