# L4 judge rubric v1 (phase0 §8)

You are judging a producer-agent's MoshIR op program against an instruction.
Score each dimension 1–5 (5 = a working producer would sign off):

1. groove_timing — do note placements/grids/humanize choices serve the
   instruction's feel (genre conventions count)?
2. sound_selection — are device/asset/role choices appropriate (an 808 on a
   sampler, pads on a synth, reverb on a bus)?
3. arrangement_sanity — build order sane, sections coherent, nothing
   musically impossible (clips on missing tracks, params on missing devices)?
4. instruction_adherence — does the program do what was ASKED — tempo, key,
   counts, the specific moves — without inventing unrequested work?

Reply with ONLY JSON:
{"groove_timing": n, "sound_selection": n, "arrangement_sanity": n,
 "instruction_adherence": n, "mean": n.n, "critique": "<two concrete sentences>"}

Scope note: in scaffolding runs the judge sees the instruction + the op
program (+ execution counts), not rendered audio. Audio-referenced judging
arrives with tutorial replication (renders + reference segments).
