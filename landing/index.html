The signal chain

One instrument. A few real modules.

Everything below runs natively on your Mac — no browser tab standing in for a DAW, no server round-trip for the parts that need to be fast.

01 / ENGINE

Native, not a tab

Built on JUCE 8 and Tracktion Engine, running natively on Apple Silicon — not Electron, not a website, no server standing between you and the audio.

02 / ARRANGE

Real multitrack arrangement

Record, drag, trim, split. Full automation, snap, and undo — built for actual production, not a demo timeline.

03 / HOST

Your own VST3 & AU

Load the instruments and effects you already own, with native plugin editor windows — not a walled-off preset list.

04 / RE-IMAGINE

Transform, don’t invent

An offline render layer — built on Stable Audio 3 — reworks a take’s timbre and texture. It edits audio you recorded, not a prompt.

05 / AGENT

Moshi, by text

Ask for a track, a fill, a render. The agent drives the same command path your own clicks do — nothing happens off to the side.

06 / JAM

Two-player Early

One session, two people, each holding a track at a time. Actively being played and hardened ahead of outside testing.

Why “transform,” not “generate”

Most AI music tools start from nothing. Mosh starts from your take.

Text-to-song
  • — Type a prompt
  • — A model assembles a full song
  • — No relationship to anything you played
Mosh
  • → Record or import a real take
  • → Re-render its timbre, texture, character
  • → The result is still yours — built from what you made

It’s a render layer, not a songwriter. You bring the performance; Mosh transforms and recombines it.
